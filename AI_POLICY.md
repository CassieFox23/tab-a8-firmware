# AI policy

This repo was made with AI. Claude, a model from Anthropic, did most of the reading and the writing, working for the maintainer, who owns all of it. So this policy is not about keeping AI out. It is about the person behind each report.

## The rules

- **Say what you used.** If an AI tool helped with an issue or a fix, name it and what it did. Using AI is fine. Hiding it is not.
- **Reports come from real reads.** A "something's wrong" report points at something you checked yourself, on a build you name. A model's guess about firmware is not a finding.
- **Every contribution has a human owner.** A named person owns each issue or pull request, has read all of it, and can explain it without asking the tool.
- **No agent posts on its own.** An issue or comment that an agent writes goes out under its owner, checked by them first.
- **Security reports** go through [SECURITY.md](SECURITY.md), checked by a person first.
- **You can give it.** Sending a fix means you have the right to release it under the GPL-3.0, like the rest of the repo.

## When it goes wrong

A report or pull request that looks machine-made and unchecked gets a short, friendly note and is closed.
