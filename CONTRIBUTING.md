# contributing

this is a write-up, a how-to and a set of scripts, kept by one person as a hobby, so replies can take a while. issues are welcome. pull requests aren't expected.

## issues

- **something's wrong** in [`Tab-A8-teardown.md`](Tab-A8-teardown.md), the [comparison](A8-vs-A10e.md), the [how-to](docs/lineageos-howto.md), the README or a script in `tools/`: use the "something's wrong" form. say which file and section, what you think is wrong, and what you found instead. a build name, an address or offset and the command you ran make it easy to check. corrections are the most useful thing you can send, since the write-up was mostly done by an AI and reviewed in passes - [how the code was read](docs/how-the-code-was-read.md) says how.
- **the how-to went differently for you**: use the same form. say your model, build and region, the step, and what the tablet or the PC showed. the how-to is a record of two flashes of one build, so a different result on another build is worth writing down.
- **a question**: use the "question" form, and say which part you read first.
- **a security problem**: don't open an issue. see [SECURITY.md](SECURITY.md).

please don't attach Samsung firmware, extracted files or keys to an issue. name the build and where to look, and the maintainer can check it against their own download.

## pull requests

they aren't expected, since the scripts are tied to one build and the write-up is one person's read. if you want to send a fix anyway, open an issue first so we can agree whether it fits.

by contributing you agree your work is released under the GPL-3.0, the same as the rest of the repo.

everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
